
# O que é um roteador

Um roteador redireciona dados da rede utilizando pacotes que contém diversos tipos de dados.

## Pacotes

Pacotes de dados possuem várias camadas nas quais carregam informações de identificação como remetente, tipo de dados, tamanho e o endereço IP do destino.
O roteador então lê essa camada priorizando os dados e escolhendo a melhor rota para a entrega do pacote.

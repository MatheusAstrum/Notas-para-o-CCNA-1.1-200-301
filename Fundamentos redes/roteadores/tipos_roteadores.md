
# Roteador principal

O roteador principal é geralmente usado por provedores de serviço ou provedores de nuvem. fornecendo largura de banda máxima para conectar roteador ou switches adicionais.

# Roteador de borda

Um roteador de borda ou gateway é o ponto de conexão mais externo de uma rede com redes externas, incluindo a internet.

Os roteadores de borda são otimizados para largura de banda e designado a conectar em outros roteadores para distribuir dados finais aos usuários. Roteadores de borda normalmente não oferecem wi-fi ou a capacidade de gerenciar redes locais totalmente. Eles normalmente têm portas Ethernet - uma entrada para se conectar a internet e várias saídas para conectar roteadores adicionais

# Roteador de distribuição

Recebe dados do roteador de borda (gateway) através de uma conexão com fio e os envia para usuários finais, normalmente via Wi-fi, embora o roteador geralmente também inclua conexões Ethernet para conectar usuários ou roteadores adicionais.

# Roteador sem fio

gateways residenciais, combinam as funções de roteadores de borda e roteadores de distribuição. Estes são roteadores comuns para redes domésticas e acesso à internet.

# Roteador virtual

São peças de software que permitem que algumas funções do roteador sejam virtualizadas na nuvem e disponibilizada como serviço. Esses roteadores são ideais para empresas grandes com necessidade de conexões complexas. Oferecendo escalabilidade, e preço baixo de entrada e a redução do gerenciamento de hardware de rede local.

# Ligações

Normalamente é necessário duas ligações

- 1 Para se comunicar com dispositivos de gravação e exibição de video, você precisa de uma conexão de rede.

- 2 Uma fonte de de alimentação é necessária para fornecer a energia elétrica da camera necessárioa para operar.

Mas se a camera é habilidade para POE, apenas a conexão de rede é neecessária para ser formada porque ela também obterá sua energia elétrica a partir desse cabo.

# Introdução

É uma técnica usada para a construção de redes de área local Ethernet com fio  que usam cabos de dados Ethernet em vez de cabos de alimentação elétricos normais e fiação para transportar a corrente elétrica necessário para operar cada dispositivo. 

PoE foi criado para acomodar dispositivos como pontos de acesso sem fio (APs) ANtes disso, vários tipos de PoE proprietários eram empregados por diferentes empresas para dar recursos de PoE.


# Conectividade 

Se certificar nos tipos de porta para se certificar que é possível conectar os dispositivos necessários. As portas não utilizadas são boas, porque permitem expandir a rede quando necessário.

# Largura de banda

A largura de banda suficiente é boa porque garante o máximo de desempenho para os usuários, é possível usar vários roteadores, hubs e switches, mas manter uma largura de dados insuficiente para a rede pode causar gargalos.

# Capacidade sem fio

Wi-fi é um dado adquirido, mas existem padrões diferentes. como o 802.11ax(wi-fi 6) pode oferecer velocidades de transmissão muito mais altas. especialmente quando vários pontos de acessos são conectados de uma vez só. Também sendo compatíveis com versões anteriores com os antigos padrões WI-FI.

# Conexões e gerenciamentos simplificados

A maioria dos roteadores fornece uma interface baseada em navegador que se conecta diretamente ao seu roteador para executar a configuração e o administrador. No entanto, muitos fabricantes agora oferecem aplicativos móveis especialmente projetados para seus dispositivos e fornecem interfaces mais intuitivas e configurações mais fáceis.

# Segurança

O roteador deve oferecer proteção por senha WPA, WPA2 ou WPA3, alguns roteadores possuem software de firewall
Outra ferramenta importante é a filtragem de endereço MAC que usa ID do dispositivo para criar uma listra branca ou negra de acesso a rede.

# Flexibilidade 

Considere roteadores que tenham uma energia sobre a porta Ethernet (PoE). fornecendo dados e eletricidade para dispositivos externos, como pontos de acesso sem fio ou cameras eliminando o cabeamento.

# Atualizações automáticas

Os roteadores contêm software que requer atualizações para manter o desempenho e segurança. Muitos fabricantes atualizam o sofware automaticamente, o que é preferível porque acontece em segundo plano sem qualquer ação de sua parte.

# Configurações mutáveis do usuário

Esse recurso permite gerencia o tráfego de rede, redes de convidados, controles parentais e configurações de segurança. A forma mais fácil de lidar se a configuração do roteador puder ser gerenciada a partir de um aplicativo ou uma interface no navegador.

# Redes de hóspedes

As redes de hóspedes são uma camada importante de segurança extra para quando os hóspedes que visitam a empresam precisam de acesso WI-FI uma rede de hóspedes limitará o acesso aos dispositivos e arquivos da empresa, enquanto ainda oferece conectividade aos visitantes.

# Controles de qualidade de serviçõ (QoS)

Combinado com ferramentas para analisar o uso em todos os usuários, esse recurso permite limitar o uso da rede a transmissões de up ou downstream, controlar determinados tipos de uso especificar largura de banda para diferentes usuários, ajudando na segurança e monitoramento da rede.

# Redes Mesh

Permite que você coloque vários transmissores WI-FI em todo os seu escritório, tudo em uma rede.


# Ponto a ponto

O cliente basicamente requer conectividade de rede ponto-a-ponto básica entre dois sites separados geograficamente que lhes permitirá enviar e receber quadros Ethernet entre si como se estivesse conectados diretamente. topologia ponto a ponto é transparente para a rede do cliente e age como se houvesse conexões físicas entre sites remotos.


As conexões tipicas de linhas alugadas dedicadas são oferecidas com esse tipo de configuração, como uma linha E1 e T1.

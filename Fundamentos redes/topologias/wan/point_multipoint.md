

# Hub and spoke WAN topology

É a topologia que é usada para conectar vários endpoints. Neste tipo de topologia WAN, existem dois papéis- Hub sendo o dispositivo central em um local que esta conectado a todos os outrso dispositivos.
- Spoke é o nome de cada um dos outros endpoints.
Os spokes estão conectados apenas ao hub não há uma conexão direta entre spokes

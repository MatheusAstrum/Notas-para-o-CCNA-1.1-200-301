
# presta serviços 

Os servidores executam tarefas especificas, como hospedar sites, gerenciar e-mails, armazenas arquivos os executar aplicativos. Variam dependendo a  finalidade do servidor.

# Escuta solicitações 

Servidores operam usando um modelo de solicitação-resposta. Eles estão sempre prontos e ouvindo em portas de rede específicas para solicitações recebidas. Quando um cliente envia uma solicitação, o servidor processa essa solicitação e envia de volta a resposta apropriada. Ele aguarda solicitações de cliente e reponde de acordo.

# Sempre ligado

Os servidores normalmente são executados 24/7 para garantir a disponibilidade contínua de serviços. As empresas normalmente aquelas que operam globalmente depende do tempo de atividade para manter os serviços acessíveis. Muitos servidores têm fontes de  alimentação redundantes, sistemas de refrigeração e redes de backup para evitar o tempo de inatividade.

# Pode ser hardware ou software

## hardware 
uma máquina potente física projetada para lidar com várias solicitações de clientes

## software  
um programa que executa funções de servidor como um serviço web

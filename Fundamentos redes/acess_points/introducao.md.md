
# Acess point sem fio (WAP)

é um dispositivo de rede que permite aos dispositivos sem fio se conectarem a uma rede cabeada. Sendo mais facil instalar WAPs para conectar todos computados ou dispositivos na rede do que usar fios e cabos.

# Por que usar um WAP para configurar uma rede sem fio?

Permite criar uma rede sem fio na rede cabeada atual, para que possa utilizar dispositivos sem fio.


Também é possivel usar um extensor de malha o WAP para aumentar o alcance e intensidade do sinal da rede sem fio. librando-se dos pontos mortos.

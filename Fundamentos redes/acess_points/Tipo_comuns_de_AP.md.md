
# AP raiz

Nesta configuração, um AP é conectado diretamente a uma LAN com fio, fornecendo um ponto de conexão para os usuários de conectividade sem fio. Se mais de um AP estiver conectado na LAN, os usuários poderão se movimentar de uma área das instalações para outra sem perder a conexão de rede.
# AP repetidor 

Um AP ou extensor de malha pode ser configurado como um repetidor autônomo para aumentar o alcance da infraestrutura ou superar um obstáculo que bloqueia a comunicação por rádio.

O repetidor encaminha o tráfego entre usuários das redes com e sem fio, enviando dados para outro repetidor ou para um AP conectado à rede cabeada. Os dados são enviados pela rota que oferece melhor desempenho para o cliente.
## Bridges

Os APS podem ser configurados como bridges raiz ou não raiz para ingressar em várias redes. Um AP nesta função vai estabelecer um link sem fio como uma bridge não raiz.  
O tráfego é transmitido pelo link sem fio para a rede com fio.
## Workgroup bridge

Os access points que estão no modo workgroup bridge podem se "associar" a outros aps como clientes e fornecer conexões da rede para dispositivos conectados às portas Ethernet.

Se a empresa precisar de conectividade sem fio para um grupo de impressoras de rede, você poderá conectar as impressoras a um hub ou switch, conectar o hub ou switch à porta Ethernet do access point e configurar o access point como uma workgroup bridge. A workgroup bridge vai ficar associada a um AP na rede.

## Unidade central em uma rede sem fio

Em uma rede sem fio, um AP atua como uma unidade raiz independente. Ele não está conectado a uma rede local com fio. Em vez disso, o AP funciona como um hub que vincula todas as estações. Servindo como ponto principal das comunicações aumentando o alcance da comunicação dos usuários de conectividade sem fio.

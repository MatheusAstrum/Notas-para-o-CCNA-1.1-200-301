

# Cabo de fibra multimodo 

Os cabos de fibra de multimodo são o tipo de cabos de fibra que transmitem dados através de seu núcleo de diâmetros maiores permitem que um transceptor médio e de modo único vários modos de luz se propaguem através dele. No entanto, isso limita o comprimento máximo de ligações de transmissão possível devido à dispersão modal. Estas fibras são assim utilizadas para a transmissão de sinais de curta distância.



# Caracteristicas

- Projetado para transportar vários modos de luz de uma vez só
- usado para transmissão de distâncias comparativamente mais curta de sinais.
    menos brilho
    alta atenuação
- Uma grande variedade de dispersão modal é possível
- O diâmetro do núcleo é de 50 um ou acima.
- Há muito mais degração de sinais
- Mais facil de fabricar e manusear
- Cabos de fibra óptica de multimodo para uso de distancias curtas são mais economicos
- os tipos OM1, OM2, OM3, OM4, são mais comuns em multimodo
- A velocidade do sinal é relativamente lenta em cabos de fibra multimodo
- Uma fonte de luz para dispositivos multimodsos geralmente é um led ou laser
- TEm a largura de banda mais baixa
- Menor custo eletrônico
- A terminação é mais facil
- Comprimentos de onda mais comuns são 850 e 1300 nm
- TIA-598C define o padrão de revestimento para aplicações não militares como é revestido com uma bainha externa laranja ou aqua dependendo do tipo.

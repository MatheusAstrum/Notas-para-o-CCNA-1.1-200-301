
# O que é IPV4

192.168.1.1

são 4 octetos de 8 bits resultando no total de 32bits
Um endereço IPV4 possui 32 bits.

Ele possui duas partes, a parte de rede e a parte de host sendo por exemplo:


192.168.1 - rede .1 - host

O endereço IP é dividido por classes (Obsoleto hoje em dia), mas nos ajuda entender

## Classe A

### Range

1.0.0.0 para 126.255.255.255 

### Subnet mask

255.0.0.0 (/8)

### Quantidade de redes

128 (somente 1-126 é usavel, 127 é reservado)

### Hosts por rede

Cerca de 16 milhões


### Usos

Grandes organizações ou ISPS

#### Nota

127.0.0.0 é reservado para o loop back


## Classe B

128.0.0.0
